# StockPicker Dashboard - Next.js Frontend

This is the frontend dashboard for the AI StockPicker trading system built with Next.js and D3.js.

## Features

- 📊 **Market Overview** - Real-time stock prices and changes
- 🔥 **Hot Stocks** - AI-detected buy/sell signals
- 📈 **Stock Analysis** - Technical indicators with D3.js charts
- 💰 **Trade Execution** - Execute single trades or full pipeline
- 📋 **Portfolio View** - Track your positions and P&L
- ⚡ **Optimization** - AI-powered portfolio optimization
- ⚙️ **Settings** - Configure trading parameters

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Make sure the API backend is running:
```bash
cd /workspaces/AI-Experts/StockPicker
python api/main.py
```

3. Run the development server:
```bash
npm run dev
```

4. Open [http://localhost:3001](http://localhost:3001) in your browser.

## Tech Stack

- **Next.js 14** - React framework
- **D3.js** - Data visualization
- **Tailwind CSS** - Styling
- **Lucide Icons** - Icons
- **Axios** - API calls
